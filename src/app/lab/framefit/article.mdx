## 원형 로고는 어떻게 만들어지나

인스타그램에서 흔히 보는 그 로고 — 글자가 원 안에 꽉 들어차 있고, 가장자리로 갈수록
자연스럽게 짧아지는 형태. 손으로 그리면 이렇게 만듭니다. 원을 하나 그리고, 글자 수만큼
세로로 칸을 나누고, 각 칸을 원의 곡선에 맞춰 채운 다음, 외곽선을 정리하고 색을 채웁니다.

이 도구는 그 과정을 그대로 코드로 옮긴 겁니다. 다만 손으로 그리는 대신
**프레임을 함수 하나로 정의**했습니다.

## 프레임 = 함수 하나

원형이든 웨이브든 아치든, 결국 필요한 정보는 하나입니다.
*"가로 위치 x에서, 이 도형은 세로로 어디부터 어디까지인가?"*

```ts
function rawSpan(frame, x) {
  switch (frame) {
    case "circle": {
      const d = (x - 0.5) * 2;
      const s = Math.sqrt(Math.max(0, 1 - d * d)) / 2;
      return [0.5 - s, 0.5 + s];   // 원의 위 호, 아래 호
    }
    case "wave": {
      const c = 0.5 + 0.17 * Math.sin(Math.PI * 2 * x);
      return [c - 0.31, c + 0.31]; // 사인파를 따라 오르내리는 띠
    }
    // …
  }
}
```

프레임 6종이 전부 이 함수의 `case` 하나씩입니다. 새 프레임을 추가하려면 여기에 한 줄 쓰면 됩니다.
왜곡 강도 슬라이더는 이 결과와 평평한 정사각형 `[0, 1]` 사이를 선형 보간할 뿐이고,
2줄 이상이면 이 구간을 줄 수만큼 나눈 뒤 분할선에 사인 곡선을 얹습니다.

## 글자를 세로로 잘라서 늘린다

보통 이런 효과는 폰트 파일에서 글리프 아웃라인을 뽑아 각 점을 변형하는 방식으로 만듭니다.
opentype.js 같은 라이브러리가 필요하고, 사용자가 올린 폰트마다 파싱이 잘 되는지 확인해야 하고,
한글처럼 글리프가 많은 폰트에서는 무거워집니다.

여기서는 다르게 접근했습니다. 글자를 캔버스에 **한 번만** 그린 다음,
그 이미지를 세로 1픽셀 폭의 열로 잘라 각 열을 해당 위치의 구간 높이에 맞춰 늘려 붙입니다.

```ts
for (let c = 0; c < cols; c++) {
  const x = xa + (xb - xa) * ((c + 0.5) / cols);
  const top = fns.top(x) * S;
  const bot = fns.bot(x) * S;
  // 소스의 c번째 열(1px)을 → 출력의 [top, bot] 구간에 늘려 그린다
  ctx.drawImage(source, c, 0, 1, srcH, xa * S + c, top, 1.4, bot - top);
}
```

가로 위치가 세로 변형만 결정하므로 역함수를 풀 필요가 없고, 열끼리 정확히 맞물려서
이음매도 생기지 않습니다. 폰트 파싱이 없으니 브라우저가 렌더할 수 있는 폰트라면
**무엇이든** — 업로드한 `.ttf`도, 한글 폰트도 — 그대로 동작합니다.

대신 가로 방향 왜곡은 포기했습니다. 레퍼런스로 삼은 스타일들이 대부분 세로 변형이라
실용적으로는 충분했고, 필요해지면 그때 메시 워핑으로 바꾸면 됩니다.

## 굵기 슬라이더의 정체

가변 폰트가 아니어도 굵기가 조절되는 이유는, 사실 굵기 축을 건드리는 게 아니라
**같은 색으로 외곽선을 덧그려서** 글자를 부풀리기 때문입니다.

```ts
ctx.lineWidth = weight * fontSize * 2;
ctx.lineJoin = "round";
ctx.strokeText(line, 0, 0);   // 바깥으로 부풀리고
ctx.fillText(line, 0, 0);     // 안을 채운다
```

`lineJoin: "round"` 덕분에 모서리가 둥글게 뭉치는데, 이게 오히려 이 스타일에 어울립니다.
아웃라인과 입체 그림자도 같은 원리 — 마스크를 여러 방향으로 조금씩 밀어 그린 합집합입니다.

## 벡터로 내보내기

캔버스 기반이라 결과물이 픽셀이라는 게 유일한 약점이었습니다.
로고로 쓰려면 벡터가 필요하니까요. 그래서 마스크를 다시 벡터로 되돌립니다.

1. **마칭 스퀘어** — 알파값 128을 경계로 이진화하고, 셀마다 네 꼭짓점 상태(16가지)에 따라
   선분을 뽑아 이어 붙여 닫힌 고리를 만든다
2. **이동 평균** — 45° 계단으로 나온 윤곽을 세 번 훑어 부드럽게 편다
3. **Ramer–Douglas–Peucker** — 편차 0.75px 이하의 점을 버려 개수를 줄인다

채움 · 아웃라인 · 그림자가 각각 별도 `<path>`로 나오고, 글자 안쪽 구멍은
`fill-rule="evenodd"`가 알아서 처리합니다. 1000×1000 뷰박스 기준 15KB 정도.

> 처음 구현했을 때 캔버스 가장자리에 걸친 도형에서 이상한 직사각형이 나왔습니다.
> 경계에 걸친 윤곽이 닫히지 못해 열린 선으로 남았고, `Z`가 그 양 끝을 직선으로
> 이어버린 탓이었습니다. 이진 그리드 바깥에 빈 1픽셀 테두리를 두르니 해결됐습니다.

## 만든 조합은 링크가 된다

슬라이더를 만질 때마다 **기본값과 다른 값만** 쿼리스트링에 실립니다.
`?text=CREATES&frame=wave&weight=0.045&depth=0.026` 같은 식이라 주소가 읽을 만하고,
누군가에게 보내면 그 사람 화면에 정확히 같은 조합이 뜹니다.
`링크 복사` 버튼이 하는 일이 그거고요.

## 직접 만져볼 것들

- **왜곡 강도**를 0으로 내리면 평범한 사각 조판이 됩니다. 1까지 올리는 동안 프레임이 어떻게 개입하는지 보세요
- **분할선 기울기**는 2줄일 때만 의미가 있습니다. 위아래 줄 사이 경계가 기울어집니다
- **세로 채움**을 줄이면 글자가 프레임 안에서 여백을 갖습니다. 로고는 대개 0.9 근처가 적당합니다
- **가이드 보기**를 켜면 프레임 윤곽(파란 점선)과 줄 경계(노란 점선)가 보입니다
